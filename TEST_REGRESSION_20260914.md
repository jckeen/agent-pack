## Root cause

`packages/connector` imports `@agentpack/core`, but `@agentpack/core`'s
`package.json` `exports` resolve to a `dist` entry that hasn't been built. Unlike
`packages/cli` (`pretest: tsc -b`) and `apps/registry` (`pretest: build:deps`), the
`connector` package has **no `pretest` build step**, so `pnpm test` runs its vitest
before core is compiled:

```
Error: Failed to resolve entry for package "@agentpack/core". The package may have
incorrect main/module/exports specified in its package.json.
 ❯ src/catalog.ts:1:1
 ❯ src/serve.ts:4:1
```

Because `pnpm -r` aborts the whole recursive run on the first package failure
(`ERR_PNPM_RECURSIVE_RUN_FIRST_FAIL`), `cli` and `registry` never reported their
counts. Confirmed green before the abort: `packages/core` (824) + `packages/db` (79)
+ `connector`'s 6 passing = 909.
